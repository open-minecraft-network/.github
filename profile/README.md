The goal of this project is to build an open source, easy to deploy fully fletched and expandable minecraft server network including auto scaling and simple deployment.

It's planned to have infrastructure configurations for multiple cloud providers.

The Minecraft stack would build on Paper with Velocity and GeyserMC to enable all Minecraft player to play together no matter the platform. :D
